# RantauFlow

AI-powered personal finance platform designed to help individuals manage expenses, monitor investments, and gain real-time financial insights.

🌐 Live Website  
https://rantauflow.app

---

# Overview

RantauFlow is an intelligent financial management platform that combines expense tracking, investment monitoring, AI assistance, and market data into one modern dashboard.

Built as a Progressive Web App (PWA), users can install RantauFlow directly on their devices without downloading it from an app store.
